

## Folder Structure

```text
├── arithmetic_exception/           # Handling illegal arithmetic operations
├── arrayindexoutofbounds_exception/ # Handling invalid array index access
├── illegalargument_exception/      # Handling inappropriate method arguments
├── multiplecatchblocks/            # Demonstrating multiple catch blocks handling
├── nullpointer_exception/          # Handling null object reference accesses
└── numberformat_exception/         # Handling failed string-to-number conversions

```

---

## 📁 arithmetic_exception
Contains examples of exceptions thrown when an exceptional arithmetic condition occurs, most commonly integer division by zero.

## 📁arrayindexoutofbounds_exception
Covers scenarios where an array is accessed with an illegal index—either a negative index or an index greater than or equal to the array's length.

## 📁 illegalargument_exception
Demonstrates exceptions thrown to indicate that a method has been passed an inappropriate, illegal, or out-of-range argument.

## 📁 multiplecatchblocks
Illustrates how to structure a single `try` block with multiple `catch` blocks to handle various specific exception types sequentially.

## 📁 nullpointer_exception
Focuses on errors that occur when an application attempts to use a `null` reference where an object instance is required, such as invoking a method or accessing a field on a null object.

## 📁 numberformat_exception
Covers exceptions thrown when an application attempts to parse or convert a string into a numeric type, but the string does not conform to the expected format.
